# Mini CMS Backend

Laravel 13 API for Mini CMS, including Sanctum authentication, role-aware post management, categories, users, Markdown content, and cover image uploads.

See the [root README](../README.md) for complete prerequisites, MySQL configuration, installation, demo accounts, and verification steps.

## Common Commands

```bash
composer install
php artisan storage:link
php artisan migrate --seed
php artisan serve
php artisan test
```
